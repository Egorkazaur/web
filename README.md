# Aether & Ink | Digital Art & Design Studio Website

A modern, responsive, fully-styled single-page website template built with HTML5, CSS3, and JavaScript.

## Files Included:
- `index.html` - Main HTML structure with semantic sections and responsive layout.
- `style.css` - Custom CSS styling with CSS variables, dark/light mode support, flexbox/grid layouts, and smooth transitions.
- `script.js` - Interactive dark mode toggle and form submission handler.

## How to Run:
1. Extract all files into a single folder.
2. Double-click `index.html` to open it in any modern web browser (Chrome, Safari, Firefox, Edge).
3. Enjoy exploring the site, test the dark/light mode toggle in the top right corner, and explore the interactive elements!
